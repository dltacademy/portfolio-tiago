# Tiago — Fundador da DLT Academy

Página estática do Tiago na DLT Academy: diferencial de ponta a ponta, frentes de atuação (sistemas de IA aplicada, sites e produtos digitais, gestão de conhecimento e operação, mercados financeiros e cripto, posicionamento e conteúdo, parcerias estratégicas), projetos em produção, método de trabalho, trajetória e contato. Português na raiz (`index.html`) e inglês em `en/`.

Domínio: [tiago.dlt.academy](https://tiago.dlt.academy) (arquivo `CNAME`), no GitHub Pages. Usa a identidade visual da DLT Academy (`styles-base.css` do portal).

Para ver localmente: `python3 -m http.server` nesta pasta.
